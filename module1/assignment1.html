What Happens Between Typing a URL and Seeing a Webpage?

When we type a URL into a web browser and press Enter, the browser first checks the URL and finds the IP address of the website using DNS (Domain Name System). Then, the browser sends a request to the web server to access the webpage. The server processes the request and sends back the required files, such as HTML, CSS, and JavaScript. The browser reads these files, processes them, and displays the webpage on the screen. This is how we access and view a website on the internet.
